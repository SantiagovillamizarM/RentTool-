- Fondo principal: Negro casi puro (#0A0A0B o #0F0F12) y gris muy oscuro (#16161A) para tarjetas y contenedores.

- Estructura de tarjetas: Bordes redondeados elegantes (`border-radius: 12px` a `16px`), bordes finos sutiles en gris oscuro/transparente (`border: 1px solid rgba(255,255,255,0.08)`), con efecto sutil de resplandor (glow) amarillo en estados active/hover.

### 3. INTEGRACIÓN TÉCNICA CON EL BACKEND (Spring Boot / REST API):
- La interfaz debe consumir la API REST del sistema bajo `/api/v1` usando Fetch API o Axios.
- Manejo de autenticación por JWT almacenado en `localStorage` o cookies seguras para los roles: CLIENTE, PROVEEDOR, ADMINISTRADOR.
- Integración de los endpoints principales:
  - POST `/api/v1/auth/login` y `/api/v1/auth/register` para el flujo de acceso.
  - GET `/api/v1/tools` con parámetros de paginación, filtros de categoría y disponibilidad por rango de fechas.
  - POST `/api/v1/reservations` para enviar solicitudes de reserva enviando `toolId`, `quantity`, `startDate`, `endDate` y `deliveryMode`.
- Respuestas de la interfaz con estados visuales claros: indicadores de carga (spinners/skeletons), estados vacíos, alertas de error uniformes y notificaciones de éxito.
