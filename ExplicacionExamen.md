# Explicación Examen Juan  Rangel



Para el examen se solicitaba un sistema registro de devolución y reporte de daños, a continuación podrá ver como es su fiuncionamiento:



## 1. Solicitar herramienta

Primero será necesario iniciar sesión como un cliente, ya una vez en el dashboard principal se deberá de buscar la herramienta deseada.

Ya una vez con la herramienta seleccionada se recomienda establecer como fecha de entrega el mismo día en el que se encuentre ahora mismo y como fecha de devolución el día siguiente, esto no es vital pero es recomendable hacerlo de esta manera  con fines de prueba:



<a href="https://ibb.co/35ym5WRP"><img src="https://i.ibb.co/cKchKtYs/image.png" alt="image" border="0"></a>



Posteriormente se va a pulsar el botón de solicitar reserva y así pasaremos a la pantalla de pagos y factura, aquí se podrá elegir si realizar el proceso mediante tarjeta de credito o debito pero también está la opción de Nequi (Recomendada), ya una vez elegido el método deberemos de completar la información.

<a href="https://ibb.co/wFLY2yK5"><img src="https://i.ibb.co/RkS7J2CR/image.png" alt="image" border="0"></a>

Si el proceso se llevó a cabo correctamente deberá de aparecer una ventana que muestre que el pago fue aprobado.



## 2. Apartado proveedor

Ahora deberemos de iniciar sesión como un proveedor, si solicitó una herramienta que se encuentra por defecto deberá de iniciar sesión con el correo de proveedor que se encuentra en el readme. Una vez ya se haya iniciado como proveedor deberá de dirigirse al apartado de solicitudes que se encuentra en el menú superior:



<a href="https://ibb.co/4nSjWRy3"><img src="https://i.ibb.co/Xr5zXxBM/image.png" alt="image" border="0"></a>

Una vez ya esté adentro de ese apartado podrá ver en la parte inferior un apartado de solicitudes de reserva en la cuál podrá ver la solicitud realizada anteriormente:



<a href="https://ibb.co/qMGHLNdT"><img src="https://i.ibb.co/VWyF0gtf/image.png" alt="image" border="0"></a>



Aquí primero deberá de aceptar la solicitud y ya una vez aceptada podrá pulsar la opción de entrega y devolución.



## 3. Entrega y devolución

Una vez todo haya sido realizado correctamente se podrá ver el apartado de esta manera:



<a href="https://ibb.co/jkbjFXcy"><img src="https://i.ibb.co/hFLTvzPB/image.png" alt="image" border="0"></a>

Aquí se puede contemplar tanto un apartado de revisión de devolución donde podremos indicar el estado en el que fue devuelto, dejar observaciones, añadir un costo adicional por cobro o perdida. Aparte también tenemos en la parte inferior un apartado de reporte de incidencias en el que se podrá especificar el tipo de la incidencia, la unidad en especifico y finalmente el apartado de descripción y ya una vez todo esté hecho podremos registrar la incidencia.
